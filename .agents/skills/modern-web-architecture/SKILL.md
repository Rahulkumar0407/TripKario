# Modern Web Architecture Skill

## 1. Next.js & React 19 Best Practices
- **Turbopack Optimization**: Keep component trees modular and clean.
- **Image Optimization**: Use Next.js `<Image>` with priority for hero visual candidates, explicit `sizes`, and optimized Unsplash parameters.
- **Client vs Server Boundaries**: Keep interactive wrappers localized and ensure data files are typed and modular.

## 2. Core Web Vitals & Accessibility
- **LCP & INP**: Ensure fast paint without blocking main-thread calculations during gesture drags.
- **ARIA & Keyboard Controls**: Ensure carousel buttons have descriptive labels (`aria-label`), visible focus rings, and proper keyboard tab flow.
